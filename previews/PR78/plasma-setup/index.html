Plasma setup

using VlasovMaxwellDispersion, Unitful

plasma = Plasma(
    Species(Proton(); n = 5u"cm^-3", T = (20u"eV", 100u"eV")),
    Species(Electron(); n = 5u"cm^-3", T = 50u"eV"),
    B0 = 5u"nT",
)
sol = solve(DispersionProblem(plasma, region, geom))

DispersionProblem normalizes the plasma itself. A dimensionless plasma skips this layer and passes NormalizedSpecies instead.

Units

Frequencies are in Ω_ref, speeds in c, so lengths are in c/Ω_ref. A wavenumber given in units of a length ℓ converts by dividing:

k̃ = (k·ℓ) / ℓ̃        ℓ̃ from `scales`

Ω_ref is the gyrofrequency of ref (positive, so sign(Ω̃ₛ) = sign(qₛ)).

Bare numbers are SI, except temperature in eV and speed in v/c. With Unitful loaded, anything dimensionally correct works: 5u"cm^-3", 5u"nT", 10u"eV", 1e6u"K", 400u"km/s", 45u"°".

Species

Species(particle, vdf = nothing; n, T | beta | vth)

Particles are Electron(), Proton(), or Particle(; z, A) with A in proton masses: Particle(z = 2, A = 4) is an alpha, Particle(z = -1, A = 1e-2) a heavy electron.

The thermal input is at most one of

keywordisscalar or
Ttemperature(T∥, T⟂)
betaplasma beta 2μ₀nT/B²(β∥, β⟂)
vththermal speed √(2T∥/m)(vth∥, vth⟂)

It sets the species' vth, which is what fills in a VDF spec below.

The VDF

Three forms. A spec — a VDF constructor called without vth_para — is completed by the species' thermal input:

Species(Proton(); n, T = (20u"eV", 100u"eV"))                 # Maxwellian, implied
Species(Proton(), BiKappa(kappa = 6); n, T)
Species(Electron(), GaussianRing(vd = 0.1, vr = 0.05); n, T)  # drifts in c
Species(Electron(), MaxwellJuttner(); n, T)                   # μ = 2/vth²

Maxwellian, GaussianRing, BiKappa, ProductBiKappa and MaxwellJuttner all defer this way. LowRankVDF and CoupledVDF wrap a spec, taking their truncation box from the same vth via cut:

Species(Proton(), LowRankVDF(BiKappa(kappa = 6); cut = 10, rtol = 1e-10); n, T)

A built VDF passes through unchanged, speeds in v/c. Grid axes may carry units:

Species(Proton(), GridVDF(vperp .* u"km/s", vpar .* u"km/s", F); n = 5u"cm^-3")

A callable scales -> AbstractVDF is for a raw f₀(p⊥, p∥) with physical parameters — here a shell at 2 v_A with a 1 keV spread:

shell(s) = let vd = 2s.vA, hi = 2s.vA + 5s.vth
    LowRankVDF((q, u) -> exp(-(sqrt(q^2 + u^2) - vd)^2 / s.vth^2); para = (-hi, hi), perp = (0, hi))
end
Species(Proton(), shell; n = 0.5e5u"m^-3", T = 1000u"eV")

It sees its own species' scales merged with the plasma-wide ones. Scales never depend on a VDF, so they are known before any VDF is built. On such a species T only sets the vth the closure reads; the true moments come from integrating f₀.

Scales

scales gives those lengths and speeds, dimensionless:

fieldis
vAAlfvén speed, from the total ion mass density
di, deinertial length c/ω_p, summed over all species of that charge sign
Omega_ref, B0reference frequency [rad/s] and field [T]
species[i](; Omega, Pi2, vth, vth_perp, n, d, rho), d = c/ω_ps, `rho = vth_perp/
s = scales(plasma)
CartesianSweep(kz = (0.01:0.008:1.0) ./ s.di)                     # k∥·dᵢ
AngleSweep(k = range(0.5, 35, 128) ./ s.de, theta = 40u"°")       # k·λₑ
AngleSweep(k = kρs ./ s.species[1].rho, theta = 30u"°")           # kρ

di/de aggregate per charge sign: two proton populations share one ω_pp. For a length built on a particle the plasma does not contain, use inertial_length:

λp = inertial_length(plasma, Proton(), 1e19u"m^-3")

Reference

ref defaults to the first species' particle, and need not be in the plasma at all:

Plasma(species...; B0, ref = Electron())     # a particle ⇒ Ω_ref = its gyrofrequency
Plasma(species...; B0, ref = 2.0e3)          # or a frequency in rad/s

Reuse one plasma across many problems and it is normalized once per problem. When that costs real time — a LowRankVDF cross, a GridVDF fit — normalize up front and pass the result instead:

plasma = NormalizedPlasma(Plasma(...))

Staying dimensionless

When the inputs are already ratios (vA/c, β, mp/me), build NormalizedSpecies directly: Ω̃ = Ω_s/Ω_ref, Π̃² = (ω_ps/Ω_ref)², speeds in c.

Pi2 = 1 / (1e-4)^2                                     # (ω_pp/ω_cp)² at vA/c = 1e-4
plasma = (NormalizedSpecies(1.0, Pi2, Maxwellian(1e-4)),
          NormalizedSpecies(-1836.15, 1836.15Pi2, Maxwellian(sqrt(1836.15) * 1e-4)))

The ion beam and relativistic pair case studies are written this way; the rest are physical.
